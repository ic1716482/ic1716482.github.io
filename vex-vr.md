## Challenge: [Basketball Drills]

### Goal
the goal of this challenge is Program the VR Robot to drive forward 1 grid square. Next, program the VR robot to drive reverse to the beginning point. Continue this pattern for 2 grid squares, then 4 grid squares. 
Program the VR Robot to drive forward 1 grid square, stop, and return back 1 grid square to where the VR Robot started without using the reverse block. The VR Robot will need to turn around to drive back to the first position. Continue this pattern for 2 grid squares, then 4 grid squares.  Build an algorithm (a process or set of rules) to move through all 1 to 8 grid squares in sequential order. The VR Robot should move to 1, go back to start, move to 2, go back to start. Continue this pattern for all 8 grid squares.
